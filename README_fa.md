# DimLifeVPN

**DimLifeVPN** یک برنامهٔ کلاینت VPN از پروژهٔ [DimLife](https://dimlife.ru/) است که برای اتصال به سرورهای VPN و مدیریت تنظیمات و اشتراک‌ها ساخته شده است.

## امکانات

- اتصال و قطع اتصال با یک لمس.
- وارد کردن و مدیریت تنظیمات و اشتراک‌های VPN.
- مشاهدهٔ وضعیت اتصال و آمار ترافیک.
- پشتیبانی از قالب‌های تنظیمات و پروتکل‌های سازگار که توسط اجزای شبکه‌ای پروژه ارائه می‌شوند.
- پروژهٔ متن‌باز و بدون تبلیغات داخلی.

پشتیبانی از پروتکل‌ها و قالب‌های مشخص به نسخهٔ برنامه و تنظیمات استفاده‌شده بستگی دارد.

## توسعه

DimLifeVPN با Flutter ساخته شده است. تنظیمات ساخت و CI در همین مخزن نگهداری می‌شوند. پروژه همچنان در حال توسعه است و نسخه‌های آماده در صفحهٔ Releases منتشر خواهند شد.

## اجزای جانبی و مجوزها

DimLifeVPN از اجزای متن‌باز دیگر استفاده می‌کند. اعلان‌های حق نشر و شرایط مجوز آن‌ها همچنان معتبر است. پیش از بازنشر نسخه‌های ساخته‌شده، مجوزهای مربوطه را بررسی کنید.
