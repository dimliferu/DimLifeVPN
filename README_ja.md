# DimLifeVPN

**DimLifeVPN** は [DimLife](https://dimlife.ru/) の VPN クライアントです。VPN 接続、設定、サブスクリプションを管理できます。

[English](README.md) · [Русский](README_ru.md) · [简体中文](README_cn.md) · [فارسی](README_fa.md) · [日本語](README_ja.md) · [Português (Brasil)](README_br.md)

## 主な機能

- ワンタップで VPN に接続・切断。
- VPN 設定とサブスクリプションのインポートおよび管理。
- 接続状態と通信量の統計を表示。
- プロジェクトのネットワークコンポーネントが提供する互換設定形式とプロトコルに対応。
- オープンソースで、アプリ内広告はありません。

対応するプロトコルや設定形式は、アプリのバージョンと使用する設定によって異なります。

## 開発

DimLifeVPN は Flutter で開発されています。ビルドと CI の設定はこのリポジトリにあります。プロジェクトは現在も開発中で、準備ができたビルドは Releases ページで公開します。

## サードパーティ製コンポーネントとライセンス

DimLifeVPN はオープンソースのサードパーティ製コンポーネントを使用しています。それぞれの著作権表示とライセンス条件は引き続き適用されます。ビルドを再配布する前に、該当するライセンスを確認してください。
