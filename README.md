# DimLifeVPN

**DimLifeVPN** — VPN-клиент проекта DimLife.

Приложение предназначено для подключения к VPN-серверам и управления конфигурациями и подписками. Проект развивается как самостоятельное приложение с собственным интерфейсом, названием и визуальным стилем.

## Основные возможности

- Подключение к VPN и отключение одним нажатием.
- Импорт и управление конфигурациями и подписками.
- Просмотр состояния подключения и статистики трафика.
- Поддержка совместимых протоколов и форматов конфигураций.
- Разработка интерфейса в фирменном стиле DimLife.

## Разработка

Проект построен на Flutter. Для сборки используется версия Flutter, указанная в `pubspec.yaml`.

Исходный код: https://github.com/dimliferu/DimLifeVPN
